FLOW 4: Client Credentials (Machine-to-Machine): Used for service-to-service calls.
-----------------------------------------------------------------------------------------------------------------------
Get Token (No User):
-------------------
curl -X POST http://localhost:7072/oauth2/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -u video-client:secret \
  -d "grant_type=client_credentials" \
  -d "scope=video.upload"

Response:
--------
{
  "access_token": "service.jwt.token",
  "token_type": "Bearer",
  "expires_in": 900
}
